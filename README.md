This repository contains the practical part of the diploma thesis by **Nurmuhammed Sabyrbayev**, student of Nukus State Technical University, on the topic *"Application of Machine Learning and Data Analysis Methods for Forecasting Economic Indicators"*.

The repository includes 2 datasets: **Share of Fixed Capital Investment in GDP** and **Fixed Capital Investment Volume (Quarterly)**, sourced from the official website of the National Statistics Committee of the Republic of Uzbekistan (https://stat.uz/ru/ofitsialnaya-statistika/investments), and 2 Jupyter Notebook files with Python/pandas scripts for analysis and forecasting of economic indicators.

Данный репозиторий — практическая часть дипломной квалификационной работы **Сабырбаева Нурмухаммеда**, студента Нукусского государственного технического университета на тему *«Применение методов машинного обучения и анализа данных для прогнозирования экономических показателей»*.

В репозитории представлены 2 таблицы: **Доля инвестиций в основной капитал в ВВП** и **Объем инвестиций в основной капитал (квартальная)**, взятые с сайта Национального комитета Республики Узбекистан по статистике (https://stat.uz/ru/ofitsialnaya-statistika/investments). Также представлены 2 Jupyter Notebook файла с Python/pandas скриптами для анализа и прогнозирования экономических показателей.
